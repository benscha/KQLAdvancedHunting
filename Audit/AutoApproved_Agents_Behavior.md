# *AutoApproved Agents Behavior*

## Query Information

#### Recommondation
it's not recommended to use this Query as a Custom Detection Rule. This Query is for Audit purposes.

#### Description
This KQL query implements a multi-stage threat hunting and correlation engine designed to detect high-risk or malicious command execution originating from local AI and automation agents.

It begins by dynamically scoping active, auto-approving agents and mapping them to specific endpoints. After isolating the process events linked to these agents, the query normalizes command-line strings by stripping whitespace and common evasion-escaping characters, while filtering out known benign baseline activity.

Each command line is evaluated against over twenty threat categories spanning traditional ATT&CK tactics, cloud credentials, container escapes, and supply-chain tampering to calculate an individual event risk score. To capture broader campaign dynamics, individual events are grouped into thirty-minute operational sessions that track progression through reconnaissance, access, and action phases. Finally, the query filters for high-impact single events, active kill-chain patterns, or cumulative session risks, returning a prioritized list of alerts categorized by severity for immediate SOC triage.

## Defender XDR
```KQL
let Lookback       = 7d;
let BaselineWindow = 23d;   // Rarity baseline before Lookback. Advanced Hunting keeps 30d, so Lookback + BaselineWindow <= 30d
let TotalWindow    = Lookback + BaselineWindow;
let SessionGap     = 30m;   // Session ends after this much inactivity (per device / agent / account)
let SessionMax     = 4h;    // Hard upper bound of one session
let MinScore       = 5;     // Single-event threshold; below this only visible via Session/Chain
let SessionMin     = 12;    // Deduplicated session score (sum of the max score per category)
let CommonUsers    = 3;     // Shape seen by >= this many accounts counts as common (FHNW: ~10 agent users, raise for larger populations)
// Whitelist is anchored to the start and must not contain chaining (;&|), otherwise "git status; <evil>" would be whitelisted
let RxWhitelist   = @"(?i)(conhost\.exe.*-ForceV1|^reg(\.exe)?\s+query\s[^;&|]*$|^([a-z]:\\[^;&|]*\\)?git(\.exe)?\s+(-c\s+\S+\s+)*(status|diff|log|fetch|pull)\b[^;&|]*$|^([a-z]:\\[^;&|]*\\)?git(\.exe)?\s.*\s(ls-files --error-unmatch|check-ignore) -- \S*settings\.local\.json$|^rundll32(\.exe)?\s+url(\.dll)?,openurl\s+https?://\S+$)";
// Boilerplate generated by the agent itself (shell wrapper, Grep tool exclusion globs, tool allow lists). Stripped before matching.
let RxAgentNoise  = @"(?i)(^bash(\.exe)?\s+-c\s+(-l\s+)?source \S*shell-snapshots\S* .*?\|\| true && eval |< /dev/null && pwd -P >\| \S+|\d?>>?\s*/dev/null|\d>&\d|\$__claudeCodeScript = \$env:CLAUDE_CODE_SHELL_LAUNCHER_SCRIPT;.*?Invoke-Expression -Command \$__claudeCodeScript|--i?glob !\S+|--(dis)?allowedTools[= ]\S+)";
// SHA256 of the base64 payload of the Claude Code PowerShell AST parser helper (-EncodedCommand). Changes with Claude Code updates; new versions show up as "Obfuscation".
let KnownAgentB64 = dynamic([
	"9a6d426c6e26160ce48e266108ec77831bba6af60f93c9d8848cc2cb6ea2e734",
	"1bc4d40820401da7f7d9a76a3d4e67b538557ff1e28e2d65fe8cbb6bb00e5d85",
	"3c1d652056b07715a5c7ea17fd7af51d4f991ff34d86ce6bfa6e4010cc7eb19a",
	"61077f27a9b85b85e16ec4a272a5531fe04a4d66544aa93d43ebf2cb50fd0143"]);
// --- Classic attacker categories ---
let RxCredentials = @"(?i)(lsass|mimikatz|sekurlsa|comsvcs.*minidump|reg(\.exe)?\s+save\s+hk|ntds\.dit|vaultcmd|cmdkey\s+/list|security\s+find-generic-password)";
let RxSecrets     = @"(?i)(\.ssh[\\/]id_|\.aws[\\/]credentials|credentials\.json|\.kube[\\/]config|gh\s+auth\s+token|\.git-credentials|\.pypirc)";
// .env / .npmrc are touched constantly in normal dev work: own category with lower score (.env.example etc. no longer match)
let RxDevSecrets  = @"(?i)((^|[\s/\\=])\.env(\s|$|[\\/;&|)])|\.npmrc)";
let RxObfuscation = @"(?i)((powershell|pwsh)(\.exe)?\b.*\s-(e|ec|en[a-z]*)\s+[a-z0-9+/=]{40,}|frombase64string|invoke-expression|\biex\b|downloadstring|downloadfile|-w(indowstyle)?\s+hidden|-nop\b|base64\s+-d|eval\(atob)";
let RxEvasion     = @"(?i)(set-mppreference|add-mppreference\s+-exclusion|wevtutil\s+cl|vssadmin\s+delete|bcdedit|netsh\s+advfirewall\s+set|sc(\.exe)?\s+(stop|delete)\s+(sense|windefend))";
let RxPersistence = @"(?i)(schtasks\s+/create|sc(\.exe)?\s+create|new-service|currentversion\\run|crontab|launchctl\s+load)";
let RxDiscovery   = @"(?i)(whoami\s+/all|\bnet(\.exe)?\s+(local)?group|nltest|get-ad(user|group|computer)|dsquery|adfind|systeminfo|\bquser\b|\bklist\b)";
let RxLateral     = @"(?i)(psexec|wmic\s+/node|enter-pssession|invoke-command\s+-computername|\brunas\b|winrs)";
let RxDestructive = @"(?i)(rm\s+-(rf|fr)\s+(/|~|/[a-z]/?|/\*|~/\*|\$HOME/?)(\s|;|&|\||$)|remove-item.*-recurse.*-force|cipher\s+/w|del\s+/f\s+/s\s+/q|format\s+[a-z]:)";
// --- Cloud, identity, container ---
let RxCloudCreds  = @"(?i)(169\.254\.169\.254|metadata\.google\.internal|az\s+account\s+get-access-token|get-azaccesstoken|aws\s+sts\s+(get-session|assume-role)|gcloud\s+auth\s+(print-access-token|application-default)|az\s+keyvault\s+secret\s+show|secretsmanager\s+get-secret|\.azure[\\/]|\.docker[\\/]config\.json|serviceaccount[\\/]token)";
let RxIdentity    = @"(?i)(new-azadserviceprincipal|new-azadappcredential|update-mgapplication|add-mgapplicationpassword|new-mgoauth2permissiongrant|new-inboxrule|set-inboxrule|add-mailboxpermission|add-mgdirectoryrolemember)";
let RxContainer   = @"(?i)(/var/run/docker\.sock|docker\s+run.*--privileged|\bnsenter\b|kubectl\s+(get\s+secret|exec|cp|port-forward)|crictl|/proc/1/root)";
let RxInfraDestroy= @"(?i)(terraform\s+destroy|az\s+group\s+delete|remove-azresourcegroup|aws\s+s3\s+rb\b|kubectl\s+delete\s+(namespace|ns|pvc)|drop\s+(database|schema)\b|drop\s+table\s+(\w+\.)?\w+\s*(;|$|cascade))";
// --- Agent-specific ---
let RxSupplyChain = @"(?i)((curl|wget)[^|;]*\|\s*(ba)?sh|pip\s+install\s+(git\+|https?://|--index-url)|npm\s+(publish|config\s+set\s+registry)|npx\s+--yes\s+https?://|--allow-scripts|postinstall|go\s+install\s+.*@|iwr[^|]*\|\s*iex)";
// Self-modification: launch flags always count, config/instruction files only together with a write operation
let RxSelfModFlag = @"(?i)(--dangerously-skip-permissions|--yolo\b|--permission-mode[= ]bypasspermissions|autoapprove)";
let RxSelfModFile = @"(?i)(\.mcp\.json|\s--mcp-config\s|mcp[_-]config\.json|\.claude[\\/]settings(\.local)?\.json|settings\.local\.json|claude\.md|\.cursorrules|\.github[\\/]workflows[\\/])";
let RxWriteOp     = @"(?i)(>>?\s*\S|\btee\b|set-content|add-content|out-file|write_text|write_bytes|\.write\(|sed\s+-i|\bcp\s|\bmv\s|copy-item|move-item)";
let RxGitTamper   = @"(?i)(git\s+remote\s+(add|set-url)|git\s+config.*url\..*insteadof|git\s+push\s+.*(--force|-f)\b|filter-branch|git\s+config\s+core\.hookspath|\.git[\\/]hooks[\\/])";
// --- C2, anti-forensics, staging, hunting ---
let RxC2          = @"(?i)(/dev/tcp/|\bsocat\b|\bngrok\b|cloudflared\s+tunnel|\bchisel\b|ssh\s+-[a-z]*R\b|localtunnel|pty\.spawn|new-object\s+system\.net\.sockets)";
let RxAntiForensic= @"(?i)(history\s+-c|unset\s+HISTFILE|HISTFILE=/dev/null|\bshred\b|truncate\s+-s\s*0\s+/var/log|journalctl\s+--vacuum|chattr\s+\+i|touch\_-[amt]\s|log\s+erase|rm\s+.*\.bash_history)";
let RxSecretHunt  = @"(?i)((grep|rg|findstr)\s[^\n]*\s(-[a-z]*r[a-z]*|/s)\s[^\n]*(passw|secret|api[_-]?key|token|begin\s+.*private)|select-string\s+.*passw|trufflehog|gitleaks)";
let RxStaging     = @"(?i)((^|[\s;&|(])7z(\.exe)?\s+a\s.*\s-p\S|(^|[\s;&|(])zip\s.*\s(-P\s|-e\s|--encrypt|--password)|tar\s+-?c[^\s]*z?f?\s+.*(/home/|/users/|\$HOME)|base64\s+-w\s*0|split\s+-b|compress-archive.*-path\s+.*(users|home))";
let RxLolBin      = @"(?i)((^|[\s\\/;&|(])(rundll32|regsvr32|mshta|msbuild|installutil|forfiles|pcalua)(\.exe)?\b|wmic\s+process\s+call\s+create|certreq\s+-post)";
// --- Exfil: hard indicators vs. context-dependent network tools ---
let RxExfilHard   = @"(?i)(certutil\s+-urlcache|bitsadmin\s+/transfer|rclone\s+(copy|sync|move)|\bnc\b\s+-)";
let RxNetTool     = @"(?i)(\bcurl\b|\bwget\b|\bscp\b|invoke-webrequest|invoke-restmethod|\biwr\b)";
let RxLocalOnly   = @"(?i)https?://(localhost|127\.0\.0\.1|\[::1\])";
let RxSuspDest    = @"(?i)(https?://(\d{1,3}\.){3}\d{1,3}|pastebin|paste\.ee|transfer\.sh|file\.io|0x0\.st|gofile|anonfiles|webhook\.site|requestbin|\.workers\.dev|\.ngrok|discord(app)?\.com/api/webhooks|api\.telegram\.org)";
let AutoApproveAgents =
	AgentsInfo
	| where Platform == "LocalAgents"
	| summarize arg_max(Timestamp, Name, Version, LifecycleStatus, RawAgentInfo) by AgentId
	| where LifecycleStatus !in~ ("Deleted", "Uninstalled")
	| extend Meta = RawAgentInfo.localAgentMetadata
	| extend AutoApprove  = tostring(Meta.autoApprove),
	         AgentExe     = tostring(Meta.relatedProcess),
	         AadDeviceId  = tolower(tostring(Meta.aadDeviceId)),
	         AgentAccount = tostring(Meta.accountName)
	| where AutoApprove =~ "true"
	| project AadDeviceId, AgentName = Name, AgentExe, AgentAccount;
let AgentDevices =
	AutoApproveAgents
	| join kind=inner (
		DeviceInfo
		| where Timestamp > ago(TotalWindow)
		| where isnotempty(AadDeviceId)
		| summarize arg_max(Timestamp, DeviceId, DeviceName) by AadDeviceId = tolower(AadDeviceId)
	) on AadDeviceId
	| project DeviceId, DeviceName, AgentName, AgentExe, AgentAccount;
let AllHits = materialize(
	AgentDevices
	| join kind=inner (
		DeviceProcessEvents
		| where Timestamp > ago(TotalWindow)
	) on DeviceId
	| where InitiatingProcessFileName        =~ AgentExe
		 or InitiatingProcessParentFileName =~ AgentExe
		 or InitiatingProcessCommandLine contains AgentExe
	| extend CmdRaw = coalesce(ProcessCommandLine, FileName)
	// Normalize: strip caret/backtick/quote escaping and collapse whitespace before matching
	| extend Cmd = replace_regex(replace_regex(CmdRaw, @"[\^`""']", ""), @"\s+", " ")
	| where not(Cmd matches regex RxWhitelist)
	// Known agent helper scripts passed via -EncodedCommand (exact hash, not prefix)
	| extend B64 = extract(@"(?i)\s-(e|ec|en[a-z]*)\s+([a-z0-9+/=]{40,})", 2, Cmd)
	| where isempty(B64) or not(hash_sha256(B64) in (KnownAgentB64))
	| extend Cmd = replace_regex(Cmd, RxAgentNoise, " ")
	| extend
		IsCredentials = Cmd matches regex RxCredentials,
		IsSecrets     = Cmd matches regex RxSecrets,
		IsDevSecrets  = Cmd matches regex RxDevSecrets,
		IsCloudCreds  = Cmd matches regex RxCloudCreds,
		IsIdentity    = Cmd matches regex RxIdentity,
		IsDestructive = Cmd matches regex RxDestructive,
		IsInfraDestr  = Cmd matches regex RxInfraDestroy,
		IsC2          = Cmd matches regex RxC2,
		IsEvasion     = Cmd matches regex RxEvasion,
		IsAntiForens  = Cmd matches regex RxAntiForensic,
		IsContainer   = Cmd matches regex RxContainer,
		IsSupplyChain = Cmd matches regex RxSupplyChain,
		IsSelfMod     = Cmd matches regex RxSelfModFlag or (Cmd matches regex RxSelfModFile and Cmd matches regex RxWriteOp),
		IsObfuscation = Cmd matches regex RxObfuscation,
		IsPersistence = Cmd matches regex RxPersistence,
		IsLateral     = Cmd matches regex RxLateral,
		IsGitTamper   = Cmd matches regex RxGitTamper,
		IsStaging     = Cmd matches regex RxStaging,
		IsSecretHunt  = Cmd matches regex RxSecretHunt,
		IsLolBin      = Cmd matches regex RxLolBin,
		IsDiscovery   = Cmd matches regex RxDiscovery,
		HasNetTool    = Cmd matches regex RxNetTool,
		// Loopback URLs are removed first, otherwise http://127.0.0.1 counts as "raw IP destination"
		HasSuspDest   = replace_regex(Cmd, RxLocalOnly, " ") matches regex RxSuspDest
	// Network tools only count as exfil when the destination or the payload is suspicious
	| extend IsExfil  = Cmd matches regex RxExfilHard
		or (HasNetTool and (HasSuspDest or IsSecrets or IsDevSecrets))
	| extend IsNetTool = HasNetTool and not(IsExfil) and not(Cmd matches regex RxLocalOnly)
	| extend Categories = array_concat(
		iff(IsCredentials, dynamic(["Credential Access"]), dynamic([])),
		iff(IsDestructive, dynamic(["Destructive Action"]), dynamic([])),
		iff(IsSecrets,     dynamic(["Secret / Token Access"]), dynamic([])),
		iff(IsDevSecrets,  dynamic(["Dev Secret File Access"]), dynamic([])),
		iff(IsCloudCreds,  dynamic(["Cloud Credential Access"]), dynamic([])),
		iff(IsIdentity,    dynamic(["Identity Persistence"]), dynamic([])),
		iff(IsInfraDestr,  dynamic(["Infrastructure Destruction"]), dynamic([])),
		iff(IsExfil,       dynamic(["Exfiltration"]), dynamic([])),
		iff(IsC2,          dynamic(["C2 / Tunnel"]), dynamic([])),
		iff(IsEvasion,     dynamic(["Defense Evasion"]), dynamic([])),
		iff(IsAntiForens,  dynamic(["Anti-Forensics"]), dynamic([])),
		iff(IsContainer,   dynamic(["Container Escape"]), dynamic([])),
		iff(IsSupplyChain, dynamic(["Supply Chain"]), dynamic([])),
		iff(IsSelfMod,     dynamic(["Agent Self-Modification"]), dynamic([])),
		iff(IsObfuscation, dynamic(["Obfuscation / Download Cradle"]), dynamic([])),
		iff(IsPersistence, dynamic(["Persistence"]), dynamic([])),
		iff(IsLateral,     dynamic(["Lateral Movement"]), dynamic([])),
		iff(IsGitTamper,   dynamic(["Git Tampering"]), dynamic([])),
		iff(IsStaging,     dynamic(["Collection / Staging"]), dynamic([])),
		iff(IsSecretHunt,  dynamic(["Secret Hunting"]), dynamic([])),
		iff(IsLolBin,      dynamic(["LOLBin Execution"]), dynamic([])),
		iff(IsDiscovery,   dynamic(["Discovery"]), dynamic([])),
		iff(IsNetTool,     dynamic(["Network Activity"]), dynamic([])))
	| where array_length(Categories) > 0
	| extend BaseScore = case(
		IsCredentials or IsDestructive, 10,
		IsSecrets or IsCloudCreds or IsIdentity or IsInfraDestr, 9,
		IsExfil or IsC2, 8,
		IsEvasion or IsAntiForens or IsContainer, 7,
		IsSupplyChain or IsSelfMod, 6,
		IsObfuscation or IsPersistence or IsLateral, 5,
		IsGitTamper or IsStaging or IsSecretHunt or IsDevSecrets, 4,
		IsLolBin, 3,
		IsDiscovery, 2,
		1)
	// Multiple categories in one command line are a strong signal on their own
	| extend Score = BaseScore + iff(array_length(Categories) > 1, 2, 0)
	| extend
		PhaseRecon  = toint(IsDiscovery or IsSecretHunt or IsContainer),
		PhaseAccess = toint(IsCredentials or IsSecrets or IsCloudCreds or IsDevSecrets),
		PhaseAct    = toint(IsExfil or IsC2 or IsStaging or IsDestructive or IsInfraDestr or IsIdentity or IsPersistence)
	// --- Shape for rarity: categories + process + matched token (digits folded) ---
	| extend MatchToken = case(
		IsCredentials, extract(RxCredentials, 0, Cmd),
		IsDestructive, extract(RxDestructive, 0, Cmd),
		IsSecrets,     extract(RxSecrets, 0, Cmd),
		IsDevSecrets,  extract(RxDevSecrets, 0, Cmd),
		IsCloudCreds,  extract(RxCloudCreds, 0, Cmd),
		IsIdentity,    extract(RxIdentity, 0, Cmd),
		IsInfraDestr,  extract(RxInfraDestroy, 0, Cmd),
		IsExfil,       strcat("exfil:", extract(RxExfilHard, 0, Cmd)),
		IsC2,          extract(RxC2, 0, Cmd),
		IsEvasion,     extract(RxEvasion, 0, Cmd),
		IsAntiForens,  extract(RxAntiForensic, 0, Cmd),
		IsContainer,   extract(RxContainer, 0, Cmd),
		IsSupplyChain, extract(RxSupplyChain, 0, Cmd),
		IsSelfMod,     strcat(extract(RxSelfModFlag, 0, Cmd), extract(RxSelfModFile, 0, Cmd)),
		IsObfuscation, extract(RxObfuscation, 0, Cmd),
		IsPersistence, extract(RxPersistence, 0, Cmd),
		IsLateral,     extract(RxLateral, 0, Cmd),
		IsGitTamper,   extract(RxGitTamper, 0, Cmd),
		IsStaging,     extract(RxStaging, 0, Cmd),
		IsSecretHunt,  extract(RxSecretHunt, 0, Cmd),
		IsLolBin,      extract(RxLolBin, 0, Cmd),
		IsDiscovery,   extract(RxDiscovery, 0, Cmd),
		extract(RxNetTool, 0, Cmd))
	| extend Shape = strcat(strcat_array(Categories, "+"), "|", tolower(FileName), "|",
		replace_regex(tolower(substring(trim(@"\s+", MatchToken), 0, 30)), @"\d+", "0"))
	| project Timestamp, DeviceId, DeviceName, AgentName, AgentExe, AgentAccount,
		AccountName, AccountUpn, Categories, BaseScore, Score, PhaseRecon, PhaseAccess, PhaseAct,
		TopCategory = tostring(Categories[0]), Shape, ExecutedCommand = CmdRaw,
		ParentProcess = InitiatingProcessFileName, ParentCommandLine = InitiatingProcessCommandLine
);
// --- Rarity (4): organisation-wide prevalence and per-account history of each shape ---
let ShapePrevalence =
	AllHits
	| summarize OrgUsers = dcount(AccountName) by PShape = Shape;
let UserBaseline =
	AllHits
	| where Timestamp <= ago(Lookback)
	| summarize by BAccount = AccountName, BShape = Shape
	| extend SeenBefore = 1;
let Hits = materialize(
	AllHits
	| where Timestamp > ago(Lookback)
	| join kind=leftouter (ShapePrevalence) on $left.Shape == $right.PShape
	| join kind=leftouter (UserBaseline) on $left.AccountName == $right.BAccount, $left.Shape == $right.BShape
	| project-away PShape, BAccount, BShape
	| extend SeenByUser = isnotnull(SeenBefore)
	| extend RarityAdj = case(
		not(SeenByUser) and OrgUsers <= 1, 3,    // new for this account and unique in the org
		not(SeenByUser), 2,                      // new for this account
		OrgUsers >= CommonUsers, -2,             // known for this account and common in the org
		0)
	// Rarity never downgrades the critical categories (BaseScore >= 9)
	| extend Score = iff(BaseScore >= 9, max_of(Score, Score + RarityAdj), max_of(1, Score + RarityAdj))
	// --- Sessions (3): sliding session per device / agent / account instead of fixed 30m bins ---
	| extend Partition = strcat(DeviceId, "|", AgentName, "|", AccountName)
	| sort by Partition asc, Timestamp asc
	| extend SessionStartTs = row_window_session(Timestamp, SessionMax, SessionGap, Partition != prev(Partition))
	| extend SessionKey = strcat(Partition, "|", tostring(SessionStartTs))
);
// --- Session scoring (1) deduplicated and kill chain (2) with order ---
let Sessions =
	Hits
	| mv-expand Cat = Categories to typeof(string)
	| summarize CatScore = max(Score) by SessionKey, Cat
	| summarize SessionScore = sum(CatScore), DistinctCats = dcount(Cat) by SessionKey
	| join kind=inner (
		Hits
		| summarize
			SessionEvents = count(),
			SessionStart  = min(Timestamp),
			SessionEnd    = max(Timestamp),
			FirstRecon    = minif(Timestamp, PhaseRecon == 1),
			FirstAccess   = minif(Timestamp, PhaseAccess == 1),
			LastAccess    = maxif(Timestamp, PhaseAccess == 1),
			LastAct       = maxif(Timestamp, PhaseAct == 1)
			by SessionKey
	) on SessionKey
	| project-away SessionKey1
	// A stage only counts if it happened before the next one
	| extend ReconToAccess = isnotnull(FirstRecon)  and isnotnull(LastAccess) and FirstRecon  <= LastAccess,
	         AccessToAct   = isnotnull(FirstAccess) and isnotnull(LastAct)    and FirstAccess <= LastAct,
	         ReconToAct    = isnotnull(FirstRecon)  and isnotnull(LastAct)    and FirstRecon  <= LastAct
	| extend KillChain = case(
		ReconToAccess and AccessToAct, "Recon > Access > Action",
		AccessToAct, "Access > Action",
		ReconToAccess or ReconToAct, "Partial",
		"None");
Hits
| join kind=inner (Sessions) on SessionKey
// Score-1 rows (plain Network Activity) are not emitted on their own just because the session is noisy
| where Score >= MinScore or (Score >= 2 and (KillChain != "None" or SessionScore >= SessionMin))
| extend Severity = case(
	Score >= 9 or KillChain == "Recon > Access > Action", "High",
	Score >= 5 or KillChain != "None" or SessionScore >= SessionMin, "Medium",
	"Low")
| extend Rank = case(Severity == "High", 1, Severity == "Medium", 2, 3)
| project Timestamp, Rank, Severity, Score, BaseScore, RarityAdj, OrgUsers, SeenByUser, TopCategory, Categories,
	KillChain, SessionScore, DistinctCats, SessionEvents, SessionStart, SessionEnd,
	DeviceName, AgentName, AgentExe, AgentAccount, AccountName, AccountUpn,
	ExecutedCommand, Shape, ParentProcess, ParentCommandLine
| sort by Rank asc, SessionScore desc, Timestamp desc
| project-away Rank
```
